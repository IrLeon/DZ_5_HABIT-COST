# Скільки коштує моя звичка

Програма в терміналі. Ви обираєте звичку (кава з собою, таксі, доставка їжі)
і кажете, скільки разів на тиждень це робите. Програма рахує, скільки грошей
на це йде за тиждень, місяць і рік, і на які мрії вистачило б цих грошей.
Дані вигадані для навчання.

## Як запустити

```
python main.py
```

Потрібен лише Python 3.10 або новіший.

## Як перевірити (тести)

```
python -m pip install -r requirements.txt
python -m pytest -q
```

## Приклад результату

```
Звичка: кава з собою, 7 раз(и) на тиждень
----------------------------------------
За тиждень: 560 грн
За місяць:  2427 грн
За рік:     29120 грн

За рік на ці гроші можна було б:
  + квитки на потяг до моря для двох
  + велосипед дитині
  + курс англійської на рік
  + вихідні в Карпатах для сім'ї
```

## Структура

```
habit-cost/
├── main.py            точка входу: питає, рахує, друкує
├── app/               пакет з кодом програми
│   ├── __init__.py    робить app пакетом
│   ├── config.py      шляхи до файлів і сталі числа
│   ├── data_loader.py читання CSV
│   ├── calculator.py  розрахунки
│   └── report.py      текст звіту
├── data/              звички, мрії і їхні ціни
├── tests/             тести
├── requirements.txt   що встановити
└── .gitignore         що не потрапляє в Git
```

Свої звички й мрії можна додати прямо в `data/habits.csv` і `data/dreams.csv`.
